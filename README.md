# Lavleen Kaur — Frontend Developer Portfolio

Single-page animated portfolio with fullscreen scroll-snap sections, a split hero layout, folder-style skill cards, and a layered animated background. Dark by default with a light theme toggle.

## 🚀 Live Demo
[https://lavleenkaur-13.github.io/lavleenkaur_portfolio/](https://lavleenkaur-13.github.io/lavleenkaur_portfolio/)

## ✨ Features

### Layout
- **Split hero** — Bitmoji on the left, intro text on the right
- **Minimal navbar** — brand on the left, Contact button on the right
- **Scroll progress bar** at the top (violet → cyan gradient)
- **Fullscreen scroll-snap** — each section fills the viewport; navigate with wheel, swipe, arrow keys, space, Home/End

### Skills section
- 4 folder cards (Web Markup, JavaScript, Responsive Design, Design to Code)
- Each tech button opens a popup with a plain-language explanation of the tool
- SVG folder graphics with per-card gradient theming

### Projects section
- 4 project cards with thumbnails, type tag, description, and Live + Code links
- Alternating left/right slide-in entry animations
- "View all on GitHub" CTA at the bottom

### Contact section
- Form (currently shows an alert on submit — not wired to a backend yet)
- Footer card with avatar, role, bio, and GitHub link

### Theme
- Dark default (`#0a0a0f` base, violet `#a855f7` + cyan `#22d3ee` accents)
- Light variant (`#fafafc` base, deeper violet/teal accents)
- Saved to `localStorage`, applied before paint to avoid FOUC

## 🎨 Animations & Effects (all currently in the build)

### Always-on background layers
- **Animated grid** with `gridPan` keyframe shift
- **Two floating glow blobs** (`glowFloat1`, `glowFloat2`)
- **Falling particles** — 22 on desktop, 12 on mobile, generated by JS on load
- **Animated SVG circuit lines** with `drawCircuit` path animation + 5 pulsing nodes
- **Film-grain noise overlay** (SVG turbulence filter, `mix-blend-mode: overlay`)

### Cursor & scroll
- **Custom cursor** — dot + lerp-followed ring, expands on interactive elements (desktop only, ≥992px with hover)
- **Animated scroll-hint mouse** at the bottom of every section except the last

### Per-section entry animations
- Bitmoji: zoom + rotate in, with two rotating rings + bob loop
- Hero heading: letter-by-letter type effect with blinking cursor
- Hero eyebrow: **text scramble** effect on every section visit
- Tagline + description: blur-up reveals
- CTA buttons: staggered fade-up
- Floating tech badges: bounce-in with individual float loops
- Section titles: **glitch effect** (red/cyan offset layers) on activation
- Cards: grid stagger fade-up
- Project cards: alternating slide from left / slide from right

> ⚠️ **Honest note:** This is a heavy build. The README previously claimed "no custom cursor, no particles, no glitch effects, no animated grid panning" — those were aspirations, not the current state. Every effect listed above is actively running. If performance is a goal, the next pass should strip the cursor, particles, circuit SVG, and grid animation.

## ♿ Accessibility
- `prefers-reduced-motion` respected — all animations, transitions, transforms, and particles disabled
- Semantic HTML5 (`<main>`, `<section>`, `<article>`, `<nav>`)
- `aria-label` on icon-only buttons and decorative SVGs
- Keyboard navigation for section switching
- Skill popup uses `role="dialog"` + `aria-modal` + Escape-to-close

> ⚠️ Caveats: `overflow: hidden` on `html, body` means users who zoom or have JS disabled cannot reach later sections. Custom cursor sets `cursor: none` site-wide — if JS fails, there's no visible cursor on desktop. Consider these before launch.

## 📤 Deploy

### Netlify (drag & drop)
1. [app.netlify.com/drop](https://app.netlify.com/drop)
2. Drag the folder → live in ~30 seconds

### GitHub Pages
```bash
git init && git add . && git commit -m "Portfolio"
git branch -M main
git remote add origin https://github.com/lavleenkaur-13/lavleenkaur_portfolio.git
git push -u origin main
```
Then: Settings → Pages → Source: `main` / `/root`.
